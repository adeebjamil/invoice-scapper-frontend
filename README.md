# Invoice Scraper Frontend

A modern React application for multilingual invoice/bill OCR scanning and table extraction to Excel.

## Features
- Drag & Drop or Camera capture bill upload
- Multilingual OCR table extraction
- In-browser editable data grid
- Export to formatted `.xlsx` Excel spreadsheets
- Responsive design for Mobile and Desktop

## Setup & Run
```bash
npm install --legacy-peer-deps
npm start
```
